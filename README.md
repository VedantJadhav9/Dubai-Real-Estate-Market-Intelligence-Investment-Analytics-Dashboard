# Dubai-Real-Estate-Market-Intelligence-Investment-Analytics-Dashboard
An interactive real estate analytics dashboard developed using Power BI to analyze Dubai housing market trends, pricing patterns, property categories, and regional distributions.

## Project Overview

This project focuses on extracting meaningful business insights from Dubai housing data using data visualization and business intelligence techniques.

The dashboard provides:
- Property pricing analysis
- Neighborhood distribution insights
- Price trend analysis
- Category-wise comparisons
- Price per square foot analysis
- Monthly market aggregation trends

---

## Tools & Technologies Used

- Power BI
- Data Analytics
- Data Visualization
- Business Intelligence
- Dashboard Design

---

## Dataset

Dataset Used: Housing Price Dataset

Features include:
- Property Price
- Square Foot Area
- Property Age
- Neighborhood Type
- Property Category
- Monthly Trends

## Key Insights

### 1. Average Pricing Overview
- Average property price: **225K AED**
- Average price per sqft: **113 AED**
- Highest property price: **492K AED**

### 2. Property Categories
- Mid-Range properties dominate the market
- Budget and High-End categories show balanced demand

### 3. Regional Distribution
Properties are evenly distributed across:
- Urban
- Rural
- Suburb

### 4. Market Trends
- Prices remain relatively stable with slight fluctuations
- Seasonal peaks observed in certain months

### 5. Price Per Sqft Analysis
| Category | Avg Price/Sqft |
|----------|----------------|
| High-End | 127 AED |
| Mid-Range | 117 AED |
| Budget | 91 AED |

### 6. Monthly Aggregation
- May & June show high market activity
- July shows decline in overall transaction value
